# 注册定点区域怪物

当收到"注册定点怪物"、"添加定点刷怪"、"编写刷怪控制器"等请求时，使用本技能。

## 用户必须提供的信息

1. **怪物中文名称**（如 `焰芒虫`）—— 显示在怪物头顶
2. **实体类型来源**—— 使用的实体（Entity class）和实体类型注册字段
   | Mod | 实体类 | 实体注册字段 |
   |---|---|---|
   | **VMD 自有** | `fun.wraq.entities.entities.*` | `ModEntityType.*` |
   | **BornInChaos** | `net.mcreator.borninchaosv.entity.FirelightEntity` | `BornInChaosV1ModEntities.FIRELIGHT` |
3. **生成坐标列表** —— 每行格式 `x y z 等级 属性倍率 掉落倍率`

## 用户可选提供的信息

4. **名称颜色主题** —— 缺省按地图区域推断（火焰区→`styleOfVolcano`，岩石区→`styleOfStone` 等）
5. **掉落物列表** —— 物品ID + 概率；缺失时使用模组默认
6. **区域边界** —— 怪物不能离开的 AABB 范围；缺失时按坐标自动估算

## 执行步骤

### 步骤1：分析用户输入的坐标并构建 Map

用户提供的每行坐标格式为：`x y z 等级 属性倍率 掉落倍率`

需转换为 `Map<Vec3, RateAttr>`：
```java
Map<Vec3, RateAttr> posToRateAttrMap = new HashMap<>();
posToRateAttrMap.put(new Vec3(3720, 72, 3730), new RateAttr(50, 1, 1));
posToRateAttrMap.put(new Vec3(3735, 74, 3748), new RateAttr(51, 1, 1));
// ...
```

`RateAttr` 三个字段含义：
- `xpLevel`：该点怪物等级
- `attributesRate`：属性倍率（影响攻击力/血量/防御等）
- `dropRate`：掉落物数量倍率（影响最终掉落）

### 步骤2：确定区域边界（Boundary）

根据坐标范围计算两组 `Vec3` 作为 `Boundary`（upPos = 最大角，downPos = 最小角）：

```java
// 坐标范围 X: 3720-3780, Z: 3730-3855, Y: 72-82
// 留出余量后：
List.of(new Boundary(new Vec3(3810, 90, 3870), new Vec3(3700, 65, 3720)))
```

规则：upPos 的 x/y/z 取最大值 + 30 余量，downPos 取最小值 - 20 余量。

### 步骤3：创建控制器 Java 类

文件路径：`src/main/java/fun/wraq/events/mob/chapter{章节}/{类名}.java`

参考模板：

```java
/** AI-Generated, 2026-07-29 */
package fun.wraq.events.mob.chapter{章节};

import fun.wraq.common.attribute.MobAttributes;
import fun.wraq.common.fast.Te;
import fun.wraq.common.fast.Tick;
import fun.wraq.common.registry.ModItems;
import fun.wraq.common.util.items.ItemAndRate;
import fun.wraq.events.mob.MobSpawnController;
import fun.wraq.process.system.element.Element;
import fun.wraq.render.toolTip.CustomStyle;
import net.minecraft.world.entity.Mob;
import net.minecraft.world.level.Level;
import net.minecraft.world.phys.Vec3;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class {类名} extends MobSpawnController {

    public static String mobName = "{怪物中文名}";
    private static {类名} instance;

    public static {类名} getInstance(Level world) {
        if (instance == null) {
            Map<Vec3, RateAttr> posToRateAttrMap = new HashMap<>();
            // ① 填入用户提供的坐标 → RateAttr
            posToRateAttrMap.put(new Vec3(x, y, z), new RateAttr(等级, 属性倍率, 掉落倍率));
            // ...

            instance = new {类名}(posToRateAttrMap, world,
                    List.of(new Boundary(new Vec3(upX, upY, upZ), new Vec3(downX, downY, downZ))));
        }
        return instance;
    }

    public {类名}(Map<Vec3, RateAttr> posToRateAttr,
                  Level level, List<Boundary> multiBoundaryList) {
        super(Te.s(mobName, {主题Style}), posToRateAttr, level, multiBoundaryList);
    }

    @Override
    public MobAttributes getMobAttributes() {
        // ② 设置该种怪物的基础属性（会被 attributesRate 乘以）
        return new MobAttributes(attackDamage, defence, manaDefence,
                critRate, critDamage, defencePenetration,
                defencePenetration0, healthSteal, maxHealth, movementSpeed);
    }

    @Override
    public Mob mobItemAndAttributeSet() {
        // ③ 返回对应实体类型的新实例
        return new {实体类}({实体注册字段}.get(), this.level);
    }

    @Override
    public Element.Unit getElement() {
        // ④ 设置元素属性（可选，返回 null 则无元素）
        return new Element.Unit(Element.{元素类型}, {元素强度});
    }

    @Override
    public List<ItemAndRate> getDropList() {
        // ⑤ 设置掉落物（会被 dropRate 乘以）
        List<ItemAndRate> drops = new ArrayList<>();
        drops.add(new ItemAndRate(ModItems.{物品}.get(), {概率}));
        drops.add(ItemAndRate.ofExp({经验值}));
        return drops;
    }

    @Override
    public String getKillCountDataKey() {
        // ⑥ 唯一击杀统计键（不要与其他控制器重复）
        return "{唯一键名}";
    }

    @Override
    public int getSpawnInterval() {
        // ⑦ 刷新间隔（秒），默认 Tick.s(36) = 36秒
        return Tick.s(60);
    }
}
```

### 步骤4：注册到 MobSpawn.setOverWorldList

文件路径：`src/main/java/fun/wraq/events/mob/MobSpawn.java`

在 `setOverWorldList(Level overWorld)` 方法中添加：

```java
overWolrdList.add({类名}.getInstance(overWorld));
```

> ⚠ 注意：如果 `getInstance` 使用 Map 模式，加入 `overWolrdList` 后父类的 `handleTick()` 会自动管理刷怪周期。不需要自己实现 tick 逻辑。

### 步骤5：添加小地图路径点（可选）

文件路径：`src/main/java/fun/wraq/process/system/wayPoints/MyWayPoint.java`

在 `overworldPointList` 中添加：

```java
add(new MyWayPoint(new Vec3(x, y, z), "{地点名}",
        colorMap.get({颜色}), CustomStyle.{主题Style}, 0));
```

## 关键约定

| 项 | 说明 |
|---|---|
| **等级基准** | `getMobAttributes()` 返回的是基础属性，会被 `posToRateAttrMap` 中的 `attributesRate` 乘以。所以基础属性应设为"等级最低点"的基准值 |
| **掉落倍率** | `posToRateAttrMap` 中的 `dropRate` 会自动注册到 `mobXpDropRateMap`，由 loot 系统应用 |
| **Singleton** | 每个控制器使用 `private static {类名} instance` + `getInstance()` 懒加载单例，避免重复注册 |
| **刷新间隔** | 通过 `getSpawnInterval()` 覆写，默认 36 秒。不同控制器的间隔错开取模，避免同一 tick 大量生成 |
| **击杀统计键** | `getKillCountDataKey()` 返回的字符串用于统计玩家击杀数，不同控制器必须唯一 |
| **父类自动处理** | 使用 Map 模式时，父类 `spawnMob()` 自动完成：自定义名 → 设置属性（×attrRate） → 设置掉落（×dropRate） |

## 常见问题

**Q: 和已经存在的同类怪物（如原本的焰芒虫）共用一个实体类型，掉落会冲突吗？**
A: 若原控制器已被注释/移除（如 `MobSpawn.java` 中旧的 `FireLightSpawnController` 被注释），则无冲突。否则原控制器和新控制器的 `MobSpawn.dropList` 会覆盖同一 entity 键。解决方案：使用时确保原有同 entity 控制器不被同时激活。

**Q: 怪物会跑出指定区域吗？**
A: 会。`Boundary` 列表定义了活动范围，`MobSpawnController` 的 `judgeOverBoundary()` 会在每 tick 检测并将会超出边界的怪物传送回随机的 `canSpawnPos`。

**Q: 同时在线玩家越多，生成数量会变化吗？**
A: 每个刷新点固定生成 3 只。`maxMobNum` 自动设为 `canSpawnPos.size() * 3`，可在构造函数中调整。
