# 注册领主级怪物

当收到"创建领主级怪物"、"注册领主级怪物"、"创建boss"等请求时，使用本技能。

## 用户必须提供的信息

1. **怪物名称**（如 `苍岩守卫`）—— 中文名，用于显示、Boss血条、击杀统计
2. **生成坐标**（如 `3577,80,2922`）—— 主怪所在位置 `x,y,z`
3. **怪物构成** —— 主怪类型 及 伴生怪物（如果有）
   - 主怪必须指明使用的实体类型（如 `Goety:HauntedArmor`、VMD自有实体等）
   - 伴生怪物及各自的坐标偏移
4. **推荐等级**（如 `40`）—— 控制怪物属性基准 & 允许获取奖励的条件

## 用户可选提供的信息

5. **掉落物列表** —— 物品ID + 概率，若未提供则使用模组默认掉落
6. **Boss特殊机制** —— 如 PlainInstance 的"6格内回血，范围外受伤"模式；若不提供则只生成无特殊机制的怪物
7. **颜色主题** —— Boss名显示颜色，缺省为 `styleOfStone` 或按地图区域推断
8. **前缀** —— 显示用的"领主级怪物"等前缀，缺省为 `NoTeamInstance.prefix()` 默认值

## 执行步骤

### 步骤1：确认实体类型来源

确定每个怪物的实体类（Entity class）和实体类型注册字段（RegistryObject field）来自哪个 mod：

| Mod | 包路径 | ModEntityType 引用方式 |
|---|---|---|
| **Goety** | `com.Polarice3.Goety.common.entities.hostile.illagers.*` | `com.Polarice3.Goety.common.entities.ModEntityType` |
| **VMD (自有)** | `fun.wraq.common.registry.ModEntityType` | `ModEntityType` |

常用 Goety 实体：
- `HauntedArmor` → `ModEntityType.HAUNTED_ARMOR`
- `Piker` → `ModEntityType.PIKER`
- `Crusher` → `ModEntityType.CRUSHER`
- `StormCaster` → `ModEntityType.STORM_CASTER`

### 步骤2：创建 Instance Java 类

文件路径：`src/main/java/fun/wraq/events/mob/instance/instances/{分类}/{怪物英文名PascalCase}Instance.java`

1. 若 `{分类}` 目录不存在则创建

#### BossBarColor 可用值
`BossEvent.BossBarColor` 枚举：`PINK`, `BLUE`, `RED`, `GREEN`, `YELLOW`, `PURPLE`, `WHITE`

### 步骤3：注册到 NoTeamInstanceModule

文件路径：`src/main/java/fun/wraq/events/mob/instance/NoTeamInstanceModule.java`

1. 添加 import：
```java
import fun.wraq.events.mob.instance.instances.{分类}.{怪物英文名PascalCase}Instance;
```

2. 在 `noTeamInstancesOverworld`（主世界）或 `noTeamInstancesNether`（下界）或 `noTeamInstancesEnd`（末地）列表末尾添加：
```java
add({怪物英文名PascalCase}Instance.getInstance());
```

### 步骤4：注册掉落物品（若掉落物为新物品）

按照《注册物品》技能为新掉落物完成以下步骤：
- 在对应注册类添加 `RegistryObject`
- 在 `zh_cn.json` / `en_us.json` 添加翻译
- 创建 `models/item/{物品ID}.json`
- 确保 `textures/item/{物品ID}.png` 存在

### 步骤5：处理现有物品依赖

若掉落物已在之前注册过（如 `armor_piece`、`world_soul_2`、`gold_coin_bag`），跳过步骤4，在 `getRewardList()` 中直接通过 `ModItems.{ITEM}` 或 `NewC1Items.{ITEM}` 引用即可。

### 步骤6：检查编译

确认所有导入均有效，无 unused import（`ServerLevel` 等不需要的导入应删除）。
