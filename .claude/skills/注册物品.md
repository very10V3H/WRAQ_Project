# 注册物品

当你收到"注册物品"或"注册一个新物品"等请求时，使用本技能。

## 用户必须提供的信息

1. **物品注册类**（如 `ModItems`、`NewC1Items`、`GemItems`等）—— Java文件路径通常为 `src/main/java/fun/wraq/.../类名.java`
2. **物品ID**（如 `gray_slime_ball`）—— 用作注册名、文件名键
3. **物品中文名称**（如 `苍岩玉膏`）—— 显示在游戏内

## 用户可选提供的信息

4. **物品名称颜色** —— 缺省为不设置 rarity
   - 可直接指定 `CustomStyle` 中已定义的 Style 常量名（如 `styleOfSakura`、`styleOfGold`、`styleOfHealth` 等）
   - 也可指定 `#rrggbb` 格式的RGB颜色值（如 `#ff5a86`）
   - 若提供颜色：需在 `CustomStyle.java` 中添加新的 Style 和 Rarity，Rarity 命名约定为 `{颜色名}_rarity`（如 `gray_slime_rarity`），Style 命名约定为 `styleOf{物品ID}`（如 `styleOfGraySlime`）
6. **是否带附魔特效**（是/否）—— 缺省为否
7. **是否是材料**（是/否）—— 缺省为否（材料会被加入 Display.materialList）

## 执行步骤

### 步骤1：若用户指定了颜色，修改 CustomStyle.java

文件路径：`src/main/java/fun/wraq/render/toolTip/CustomStyle.java`

1. 在文件末尾（最后一个 `}` 前）添加：
   ```java
   public static Style styleOf{物品IDPascalCase} = Style.EMPTY.withColor(TextColor.parseColor("{颜色值}"));
   public static Rarity {物品IDPascalCase}_rarity = Rarity.create("{物品ID小写snake}", style -> {
       return style.applyTo(CustomStyle.styleOf{物品IDPascalCase});
   });
   ```
   - `{物品IDPascalCase}`：将物品ID转为PascalCase，如 `gray_slime_ball` → `GraySlimeBall`
   - `{颜色值}`：用户提供的 `#rrggbb`
   - `{物品ID小写snake}`：物品ID的小写snake_case（即原始ID）
2. 若还需要Bold/Italic变体，参考已存在的模式添加。

### 步骤2：在指定注册类中添加 RegistryObject

1. 读取指定的注册类 Java 文件
2. 在类中找到 `ITEMS.register(...)` 相关代码区域
3. 根据是否带附魔特效和是否是材料，决定 `WraqItem` 构造参数：

| 附魔 | 材料 | 代码 |
|------|------|------|
| 否 | 否 | `new WraqItem(new Item.Properties()${有rarity? `.rarity(CustomStyle.{rarity字段})` : ""})` |
| 是 | 否 | `new WraqItem(new Item.Properties()${有rarity? `.rarity(CustomStyle.{rarity字段})` : ""}, false, true)` |
| 否 | 是 | `new WraqItem(new Item.Properties()${有rarity? `.rarity(CustomStyle.{rarity字段})` : ""}, true, false)` |
| 是 | 是 | `new WraqItem(new Item.Properties()${有rarity? `.rarity(CustomStyle.{rarity字段})` : ""}, true, true)` |

   > 若用户指定了Color引用了 CustomStyle 中的新 Rarity，则需要添加 import：
   > `import static fun.wraq.render.toolTip.CustomStyle.{rarity字段};`

4. 添加行：
   ```java
   public static final RegistryObject<Item> {物品ID常量} = ITEMS.register("{物品ID}",
           () -> new WraqItem(new Item.Properties()${有rarity? `.rarity({rarity字段})` : ""}${构造函数参数}));
   ```
   - `{物品ID常量}`：物品ID的全大写snake_case，如 `gray_slime_ball` → `GRAY_SLIME_BALL`
   - `{物品ID}`：原始小写ID
   - `{rarity字段}`：若指定颜色，使用对应 Rarity 字段名

### 步骤3：修改 lang 文件

#### zh_cn.json
文件路径：`src/main/resources/assets/vmd/lang/zh_cn.json`
- 在 `"item.vmd.{物品ID}"` 处查找是否已存在
- 若不存在，在合适位置添加键值对：
  ```json
  "item.vmd.{物品ID}": "{中文名称}"
  ```

#### en_us.json
文件路径：`src/main/resources/assets/vmd/lang/en_us.json`
- 在 `"item.vmd.{物品ID}"` 处查找是否已存在
- 若不存在，由模型将中文名称翻译为英文后添加：
  ```json
  "item.vmd.{物品ID}": "{英文翻译}"
  ```

### 步骤4：创建 model JSON 文件

文件路径：`src/main/resources/assets/vmd/models/item/{物品ID}.json`

内容：
```json
{
  "parent": "minecraft:item/generated",
  "textures": {
    "layer0": "vmd:item/{物品ID}"
  }
}
```

若文件已存在则跳过。

### 步骤5：检查 texture 文件

检查 `src/main/resources/assets/vmd/textures/item/{物品ID}.png` 是否存在。

### 步骤6：报告结果

向用户报告：
1. ✅ 已在 `{注册类}` 中添加 `{物品ID常量}` 注册
2. ✅ 已在 zh_cn.json / en_us.json 中添加翻译（或注明已存在）
3. ✅ 已在 models/item 中创建/跳过 model JSON
4. ⚠️ textures/item 中 **{有/无}** `{物品ID}.png` 文件 —— 若缺失，告知用户需要自行准备该文件
5. 若创建了新颜色/Rarity，告知用户在 `CustomStyle` 中添加了 `styleOf{...}` 和 `{...}_rarity`
