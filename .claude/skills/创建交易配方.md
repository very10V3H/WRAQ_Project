# 创建交易配方

当收到"创建交易配方"、"创建商人"、"添加交易"、"添加兑换"等请求时，使用本技能。

## 用户必须提供的信息

1. **商人名称**（如 `阶段3商人`）—— 显示名称和代码名称
2. **商人风格/颜色**（如 `styleOfStone`）—— 来自 `CustomStyle` 的 Style 常量
3. **交易列表** —— 每项交易的 材料(物品+数量) → 产品(物品+数量)

## 执行步骤

### 步骤1：确认所有物品的 Java 引用

查找交易中涉及每件物品的 `RegistryObject<Item>` 字段所在类：

| 物品中文名 | 注册名 | 查找方式 |
|---|---|---|
| 苍岩玉膏 | `gray_slime_ball` | 搜索 `zh_cn.json` 找到注册名 → 搜索 `*.java` 找到字段 `GRAY_SLIME_BALL` → 所在类 `NewC1Items` |
| 钢铁手盾 | `mine_shield` | 同上 → `MINE_SHIELD` → `ModItems` |
| 铜制锻造锤 | `copper_hammer` | 同上 → `COPPER_HAMMER` → `ModItems` |

**快速定位方法：**
```bash
# 1. 在 zh_cn.json 中找到注册名
grep "钢铁手盾" src/main/resources/assets/vmd/lang/zh_cn.json
# 输出: "item.vmd.mine_shield": "钢铁手盾"

# 2. 在 Java 文件中找到 RegistryObject
grep "mine_shield\|MINE_SHIELD" src/main/java -r --include="*.java"
# 输出: ModItems.java: ... MINE_SHIELD = ITEMS.register("mine_shield", ...)
```

### 步骤2：确认物品的导入路径

确定物品字段所在的类，导入该类：

```java
import fun.wraq.common.registry.ModItems;                        // ModItems.XXX
import fun.wraq.series.overworld.c1.NewC1Items;                  // NewC1Items.XXX
import fun.wraq.series.overworld.newarea.NewAreaItems;            // NewAreaItems.XXX
// 其他系列物品按所在包导入
```

### 步骤3：添加 `stage{N}()` 方法

文件路径：`src/main/java/fun/wraq/render/gui/villagerTrade/TradeListNew.java`

在 `stage2()`（或最后一个 stage 方法）之后添加新方法：

```java
public static void stage{N}() {
    MyVillagerData.setMyVillagerDataWraq3("{商人名称}", "{商人名称}", CustomStyle.styleOf{Style},
            List.of(
                    Pair.of(Is.n({产品物品字段}),                                // 交易 1
                            List.of(Is.n({材料1字段}, {数量1}), Is.n({材料2字段}, {数量2}))),
                    Pair.of(Is.n({产品物品字段}),                                // 交易 2
                            List.of(Is.n({材料1字段}, {数量1}))),
                    // ... 更多交易
            ));
}
```

**`Pair` 和 `Is` 用法说明：**

| 方法 | 含义 | 示例 |
|---|---|---|
| `Pair.of(产品, 材料列表)` | 一对交易配方 | `Pair.of(Is.n(PRODUCT), List.of(...))` |
| `Is.n(item)` | `new ItemStack(item.get(), 1)` | `Is.n(MINE_SHIELD)` |
| `Is.n(item, count)` | `new ItemStack(item.get(), count)` | `Is.n(COPPER_COIN, 800)` |

**交易配方的数据结构：**
```
Pair<ItemStack, List<ItemStack>>
  ├── .first  = 产品 (单个 ItemStack)
  └── .second = 材料列表 (多个 ItemStack)
```

### 步骤4：在 `init()` 中添加调用

在 `init()` 方法的 `stage()` 调用链末尾添加：

```java
public static void init() {
    stage1();
    stage2();
    stage3();   // ← 新增
    curio1();
    // ...
}
```

### 步骤5：添加必要的 import

在文件顶部 import 区域添加新引入的物品类：

```java
import fun.wraq.series.overworld.c1.NewC1Items;       // 新增
import fun.wraq.series.overworld.newarea.NewAreaItems;  // 新增
```

如该类已在文件顶部通过 `import static fun.wraq.common.registry.ModItems.*;` 静态导入，则 `ModItems` 中的字段可直接使用，无需额外 import。

### 步骤6：验证编译

确认：
- 所有物品字段名拼写正确（注意大小写，如 `COPPER_COIN` 而非 `COPPER_COIN`）
- 包名正确（`NewAreaItems` 在 `fun.wraq.series.overworld.newarea` 而非 `newarea`）
- `init()` 中 `stage{N}()` 的调用顺序位于 `curio1()` 之前（如要保持 stage 分组）

## 参考示例

### `stage1()` — 阶段1商人
```java
public static void stage1() {
    MyVillagerData.setMyVillagerDataWraq3("阶段1商人", "阶段1商人", CustomStyle.styleOfPlain,
            List.of(
                    Pair.of(Is.n(PLAIN_SWORD_0), List.of(Is.n(COPPER_COIN, 30))),
                    Pair.of(Is.n(PLAIN_BOW_0), List.of(Is.n(COPPER_COIN, 30))),
                    // ...
            ));
}
```

### `stage3()` — 阶段3商人（多材料交易）
```java
public static void stage3() {
    MyVillagerData.setMyVillagerDataWraq3("阶段3商人", "阶段3商人", CustomStyle.styleOfStone,
            List.of(
                    Pair.of(Is.n(MINE_SHIELD),
                            List.of(Is.n(NewC1Items.GRAY_SLIME_BALL, 30), Is.n(COPPER_COIN, 800))),
                    Pair.of(Is.n(NewAreaItems.STONE_SPIDER_KNIFE_0),
                            List.of(Is.n(NewC1Items.GRAY_SLIME_BALL, 30), Is.n(COPPER_COIN, 800))),
                    Pair.of(Is.n(COPPER_HAMMER),
                            List.of(Is.n(COPPER_COIN, 100)))
            ));
}
```

### `curio1()` — 宝石商人（多材料、多数量）
```java
public static void curio1() {
    MyVillagerData.setMyVillagerDataWraq3("宝石商人", "宝石商人", CustomStyle.styleOfGold,
            List.of(
                    Pair.of(Is.n(PLAIN_RING),
                            List.of(Is.n(COPPER_COIN, 888), Is.n(COMPLETE_GEM), Is.n(PLAIN_RUNE))),
                    // ...
            ));
}
```
